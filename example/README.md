# Configuring a BIDS-compliant project folder

You need to set the file `conf.yaml` inside the folder `BIDS_myProject_7T` in order to run the pipeline.  The file `analysis. yaml` is only needed only if the python scripts are used, once the whole pipeline has been run.  Template versions with mock information inside the folder `BIDS_myProject_7T` will help you create your own working files.
